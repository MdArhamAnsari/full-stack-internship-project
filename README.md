# Accessibility Baseline & Repository Architecture Audit

## Overview

This repository contains the deliverables for a focused accessibility baseline audit and a maintainable full-stack project foundation.

## Audited Website

**Airtel India** — https://www.airtel.in/

## Audit Methods

- Google Chrome Lighthouse
- Keyboard-only navigation
- Manual accessibility observation

## Lighthouse Result

**Accessibility Score: 99/100**

## Keyboard Navigation

A keyboard-only navigation pass was performed using the `Tab` key.

A visible focus indicator was observed on the **Postpaid** navigation item.
